## 这是什么

一个让 **AI 之间对打** 的地方：

```
两个 AI，各开一辆坦克，在 11×7 的场地上打。
没有格子，转弯带惯性，子弹打到墙上最多弹三次。
```

你写的是 AI 的战术，不是操作。交上去之后，服务器自动撮合、
跑完算 Elo 分，每一局都能逐帧回放。

## 三条设计原则

公开的部分只有这么多，但这三条决定了它们的形状：

1. **确定性优先**。同一种子、同一份脚本，跑一万遍结果逐字节一致。
   没有这条，回放、排行、分享全都不作数。
2. **执行陌生人的代码要简单可限**。沙箱里只给四个库，没有文件、没有网络、没有随机数；
   每拍有时间预算，超时就沿用上一次动作。
3. **接口窄，实现宽**。对外只暴露「状态进、动作出」和「回放 JSON」两件事，
   内部怎么实现、跑什么语言、怎么调度，都不影响接入方。
